# 飞行检查单编写与校验工具（sologsb-1030）

用于按飞行阶段编写、校验、复核和冻结操作检查单。项目实现完整的数据模型、本地持久化、版本控制、快捷键、拖拽排序、校验、修订差异与打印导出。

## 功能

- 阶段与检查项：维护飞行阶段、挑战语、预期回应、关键标记、前置条件和异常处置。
- 快速录入：可使用 `/` 聚焦挑战语，`Cmd/Ctrl+Enter` 新增检查项，`Alt+↑/↓` 调整当前项位置。
- 拖拽排序：检查项可拖动并跨阶段移动，阶段也可调整先后顺序。
- 整批原子调整：飞行阶段、检查项、前置条件在同一份草稿上一次演算、一次提交：
  - 目标阶段调整后超过 24 项打印页容量时整批拒绝；
  - 重算依赖环（Tarjan 强连通分量）与已删除/悬空引用，任一不满足即拒绝并保留原顺序，冲突原因标注在相关检查项旁；
  - 调整成立后，被移动项及其传递下游的「已确认」状态失效并记录原因，阶段排序导致前置不可达时同样失效。
- 机组确认：每项可勾选确认；顺序、阶段、前置条件或所依赖项变化时自动失效，需重新确认。
- 旧表兼容：打开旧版本数据时补齐字段与依赖，无法归属阶段的检查项进入「待整理」阶段，无法归属的列收进「待整理列」面板，可指定归入字段或丢弃。
- 发布校验：
  - 重复挑战语与高频回应；
  - 缺少挑战语或预期回应；
  - 自引用、多节点依赖环、已删除或顺序不可达的前置条件；
  - 飞行阶段顺序异常；
  - 单阶段检查项超过 24 项打印页容量；
  - 空阶段提示。
- 发布流程：编辑中 → 复核中 → 冻结；存在阻断错误时不能提交复核或冻结。冻结前强制落盘，保存失败则不冻结（只接受已持久化的最新结果）。
- 保存可靠性：所有编辑写入浏览器 `localStorage`；写入失败（如配额超限）时自动恢复到最近一次成功保存（移动前）的状态并提示。
- 修订控制：冻结后可创建新修订；冻结快照保留阶段、检查项、时间和复核说明。
- 版本差异：可选择当前版本或任意冻结版本作为基准与比较版本，显示新增、删除、修改和阶段调整。
- 键盘与历史：支持撤销、重做、手动保存，最近 40 次编辑可回退。
- 只读预览与打印：提供对话框预览、浏览器打印/PDF，以及独立打印版 HTML 导出；打印页显示确认状态与失效原因，并标注超容量阶段。

## 技术栈

- React 19
- TypeScript 5
- Radix Themes
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`。宿主机正式端口由根目录 `docker-compose.yml` 映射为 `10030:80`，源码不硬编码宿主端口。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1030 .
docker run --rm -p 10030:80 sologsb-1030
```

多阶段镜像构建完成后由 nginx 监听容器 `80`，只提供静态前端资源。

## 数据说明

浏览器存储键为 `sologsb-1030-workspace-v1`，主题偏好使用 `sologsb-1030-theme`。当前版本内置 C172 示例检查单及两个历史冻结版本。
