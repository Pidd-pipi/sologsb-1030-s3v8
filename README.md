# 飞行检查单编写与校验工具（sologsb-1030）

用于按飞行阶段编写、校验、复核和冻结操作检查单。项目实现完整的数据模型、本地持久化、版本控制、快捷键、拖拽排序、校验、修订差异与打印导出。

## 功能

- 阶段与检查项：维护飞行阶段、挑战语、预期回应、关键标记、前置条件和异常处置。
- 快速录入：可使用 `/` 聚焦挑战语，`Cmd/Ctrl+Enter` 新增检查项，`Alt+↑/↓` 调整当前项位置。
- 拖拽排序：检查项可拖动并跨阶段移动，阶段也可调整先后顺序。
- 批量换阶段：在同一份草稿中勾选多个检查项与目标阶段，预检通过后一次性提交。
  - 调整前先校验**目标阶段打印页容量（24 项）**，超过即拒绝该项；
  - 在移动后布局上重算**已删引用、前置条件依赖环（Tarjan）与全部前置可达性**（含“别人依赖我”）；
  - 冲突项**保留原顺序**，原因标注在冲突项旁；其余项正常执行（部分成功）；
  - 执行后，移动项与依赖链下游的**已有确认失效并写入原因**，可逐项重新确认。
- 确认台账：检查项可标记机组确认；顺序或内容变化后确认失效，冻结前必须重新确认。
- 旧表迁移：打开旧版本数据时升级 schema、补齐字段与依赖；自引用剔除、已删引用进入「待整理」，孤儿检查项进入「待整理」阶段，清空后才允许冻结。
- 保存安全：写入浏览器失败时自动恢复到移动前状态；冻结前强制落盘，**只接受最新结果**。
- 发布校验：
  - 重复挑战语与高频回应；
  - 缺少挑战语或预期回应；
  - 自引用、已删除或顺序不可达的前置条件；
  - 飞行阶段顺序异常；
  - 空阶段提示。
- 发布流程：编辑中 → 复核中 → 冻结；存在阻断错误时不能提交复核或冻结。
- 修订控制：冻结后可创建新修订；冻结快照保留阶段、检查项、时间和复核说明。
- 版本差异：可选择当前版本或任意冻结版本作为基准与比较版本，显示新增、删除、修改和阶段调整。
- 键盘与历史：支持撤销、重做、手动保存，最近 40 次编辑可回退。
- 离线保存：所有数据写入浏览器 `localStorage`。
- 只读预览与打印：提供对话框预览、浏览器打印/PDF，以及独立打印版 HTML 导出。

## 技术栈

- React 19
- TypeScript 5
- Radix Themes
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`。宿主机正式端口由根目录 `docker-compose.yml` 映射为 `10030:80`，源码不硬编码宿主端口。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1030 .
docker run --rm -p 10030:80 sologsb-1030
```

多阶段镜像构建完成后由 nginx 监听容器 `80`，只提供静态前端资源。

## 数据说明

浏览器存储键为 `sologsb-1030-workspace-v1`，主题偏好使用 `sologsb-1030-theme`。本地数据 schema 已升级到 v2，旧数据在打开时自动迁移（依赖缺失列入「待整理」）。当前版本内置 C172 示例检查单及两个历史冻结版本。
